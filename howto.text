'ADMIN' | 'INSTRUCTOR' | 'STUDENT'

ADMIN — จัดการ users ทั้งหมด, จัดการ courses, เข้าถึงได้ทุกหน้า (รวม Admin Panel + Instructor)
INSTRUCTOR — สร้าง/จัดการ courses, lessons, quizzes ของตัวเอง เข้า Instructor Panel ได้
STUDENT — ลงเรียน, เรียน course, ทำ quiz, ดู certificate (default role ตอน register)

ทุกคนเห็น: Dashboard, My Courses, Profile
ADMIN เพิ่ม: Admin Panel, Instructor
INSTRUCTOR เพิ่ม: Instructor

Flow ทั้งระบบ ตั้งแต่เริ่มจนได้ใบ Certificate
ต้องสร้าง User 2 คน
1. ADMIN (สร้างทีแรก)
ใช้ตอน register แล้วเปลี่ยน role ใน database เป็น ADMIN
หรือสร้างผ่าน Supabase dashboard แล้ว insert ในตาราง users ด้วย role: 'ADMIN'
หน้าที่: จัดการ users, อนุมัติ courses
2. INSTRUCTOR (สร้างที่สอง)
Register ปกติ → เปลี่ยน role เป็น INSTRUCTOR (ผ่าน Admin panel หรือ database)
หน้าที่: สร้าง Course → เพิ่ม Lessons → สร้าง Quiz → เพิ่ม Questions
3. STUDENT (สร้างที่สาม)
Register ปกติ → role เป็น STUDENT อัตโนมัติ
หน้าที่: ลงเรียน → เรียน lessons → ทำ quiz → ได้ certificate
Flow ทั้งหมด
1. ADMIN register + เปลี่ยน role → ADMIN
   ↓
2. INSTRUCTOR register + เปลี่ยน role → INSTRUCTOR  
   ↓
3. INSTRUCTOR สร้าง Course (status: DRAFT)
   ↓
4. ADMIN เปลี่ยน Course status → PUBLISHED
   ↓
5. INSTRUCTOR เพิ่ม Lessons ใน Course
   ↓
6. INSTRUCTOR สร้าง Quiz + Questions ใน Course
   ↓
7. STUDENT register (role: STUDENT อัตโนมัติ)
   ↓
8. STUDENT ลงเรียน Course (Enroll) → status: ACTIVE, progress: 0%
   ↓
9. STUDENT เข้าเรียน Lesson → กด "Mark as Complete"
   → POST /api/progress → upsert lesson_progress
   → enrollment.progress_percent อัปเดตอัตโนมัติ (trigger)
   ↓
10. ทำซ้ำจนครบทุก Lesson → progress = 100%
    → ระบบ auto เปลี่ยน enrollment.status → COMPLETED
    → ระบบ auto สร้าง Certificate (ใน POST /api/progress)
   ↓
11. STUDENT ดู Certificate ที่หน้า Profile > Certificates tab
สรุปลำดับที่ต้องทำ
ลำดับ	ผู้ทำ	action	หน้า/ API
1	คุณ	สร้าง ADMIN	Register + แก้ DB
2	คุณ	สร้าง INSTRUCTOR	Register + แก้ role ผ่าน Admin panel
3	INSTRUCTOR	สร้าง Course	/instructor > New Course
4	ADMIN	Publish Course	/admin > เปลี่ยน status
